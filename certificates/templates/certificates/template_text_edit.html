Available Placeholders

{patient_name} Patient's full name
{age} Patient's age
{sex} Patient's sex
{college_info} e.g. "from College of Arts and Sciences - 3rd Year, "
{position_info} e.g. "Faculty - IT Department, "
{exam_date} Examination date
{diagnosis} Diagnosis text
{rest_date} Single rest date
{rest_from} Rest period start
{rest_to} Rest period end
{return_date} Return to work date
{work_assessment} Work assessment result
{fitness_status} Fitness clearance
{activity_name} Activity name
{restrictions} Work restrictions
{college} Full college name
{college_abbr} College abbreviation
{year_level} Year level
{position} Staff position
{department} Staff department

Note: HTML tags are not allowed. Use blank lines between paragraphs for spacing. Placeholders not used in the text will be left as-is.
